# Contributing to ABC4RD

Thank you for helping build verifiable, accessible international education.

## Before opening a pull request

1. Keep the change focused and explain the learner or operator impact.
2. Add or update tests for behavioral changes.
3. Run the Academy Core, Digital Twin and relevant deployment checks.
4. Do not commit secrets, personal data, course manuscripts or production exports.
5. Preserve append-only audit semantics and payment idempotency guarantees.

## Pull requests

Describe what changed, why it is needed, how it was verified and any migration or
security implications. Draft pull requests are welcome for early technical review.

## Conduct

Be respectful, evidence-driven and constructive. Harassment, discrimination and
publication of private information are not accepted.
