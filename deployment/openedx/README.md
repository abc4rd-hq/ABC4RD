# Развёртывание Open edX для ABC4RD

Этот каталог предназначен для **нового отдельного production-сервера**, а не для
действующего сервера сайтов и не для установки на Mac.

## Целевая конфигурация

- OVHcloud VPS-4, европейский регион;
- Ubuntu 24.04 LTS;
- 8 vCore, 24 ГБ RAM, 200 ГБ NVMe;
- открыты входящие TCP 22, 80 и 443;
- DNS `learn.abc4rd.org`, `studio.abc4rd.org`, `apps.learn.abc4rd.org` и `meilisearch.learn.abc4rd.org` указывает на сервер;
- Docker Engine 24+ и Docker Compose v2;
- Tutor `21.0.8`, соответствующий Open edX Ulmo.

## Подготовленные файлы

- `.env.example` — несекретные параметры доменов и платформы;
- `check-server.sh` — безопасная проверка ресурсов до установки.
- `bootstrap-host.sh` — базовая подготовка и защита Ubuntu-хоста;
- `sshd-hardening.conf` — правила SSH без root- и password-входа.

## Порядок первого запуска

1. Скопировать `.env.example` в `.env` на новом сервере и заполнить контактный
   адрес. Секреты в этот файл не добавлять.
2. Запустить `./check-server.sh`. Установка разрешена только при результате
   `ГОТОВ К УСТАНОВКЕ`.
3. Установить Docker из официального репозитория Docker.
4. Установить Tutor `21.0.8` в отдельное виртуальное окружение.
5. Задать `LMS_HOST`, `CMS_HOST`, `PLATFORM_NAME`, `CONTACT_EMAIL` и HTTPS.
6. Выполнить `tutor local launch`.
7. Создать администратора и проверить обе веб-части: обучение и Studio.

Фактическая установка выполнена на отдельном VPS после успешной проверки его
параметров. Действующий сервер с другими проектами не затрагивался.
