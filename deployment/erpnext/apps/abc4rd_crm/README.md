# ABC4RD CRM

Минимальное Frappe-приложение этапа 5А. Оно добавляет одну карточку участника,
обращения и непрозрачные audit references. Приложение не содержит фикстур с PII,
не копирует учебный прогресс Open edX и не ведёт платёжный ledger.

Источник истины и полная матрица полей описаны в `docs/08-ERPNEXT-CRM.md`.
