# ABC4RD learner portal

The portal is a learner-facing shell in front of existing systems. Keycloak
authenticates through `oauth2-proxy`; the portal itself stores no passwords and
receives only verified OIDC headers on the private Tutor network.

It displays a non-PII projection generated by `deployment/integration`, links to
Open edX and Element, provides the first library reader, and issues a signed
technical-pilot PDF certificate only when the synchronized Open edX grade is
passing. The PDF is explicitly not a state diploma or the future AI-reviewed
Verifiable Credential.

Production secrets belong in `.env` with mode `600` and in 1Password. The
public verification endpoint is served separately on `verify.abc4rd.org`.
