# Security policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue.

Send a concise report to [admin@abc4rd.org](mailto:admin@abc4rd.org) with:

- the affected component and version;
- reproduction steps;
- the expected and observed behavior;
- the practical impact;
- a proposed fix, if available.

Do not include real learner data, credentials, wallet secrets or payment data.
ABC4RD will acknowledge valid reports and coordinate disclosure after a fix is
available.

## Scope

This repository contains open-source platform code and deployment templates.
Production infrastructure, third-party services and course content are outside
the public repository and may have separate security contacts.
